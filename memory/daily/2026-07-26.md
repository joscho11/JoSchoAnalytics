## Bugs fixed (14)

All in `fantasy/seasonal_projections/`. Rebuilt `season_dataset_2014_2025.csv` and
`season_dataset_2014_2026.csv` from the pinned snapshots; row counts unchanged at 7,350 and
8,273.

- **`target_share` was not a share.** It aggregated the *mean of weekly shares*, so per-team
  season totals averaged **1.384** and reached 2.188 — a 2-game 40%-share player counted the
  same as a 17-game one. Now volume-weighted at (player, season, team) grain: totals are
  exactly **1.0000**. This propagates to `prior_target_share` (a model feature) and to
  `vacated_target_share`, which sums it.
- **Team-code chaos across three feeds.** `load_player_stats` is modernized in every season
  (ARI/BAL/CLE/HOU/LA/LAC/LV), `load_rosters_weekly` emits legacy GSIS codes
  (ARZ/BLT/CLV/HST/SL/SD/OAK) through 2019, and `load_schedules` uses era codes
  (STL/SD/OAK). `context_team` carried the legacy codes into the coach, QB1 and vacated
  joins, which silently produced NaN or a hard 0. Added a single `TEAM_CANON` map applied to
  every feed. Side benefit: folding the relocations onto one code lets
  `coaches.groupby("team")["coach"].shift(1)` bridge STL→LA, SD→LAC and OAK→LV, which
  previously broke `prev_coach` at each move — that was the real cause of the LAC 2017
  17-row `coach_changed` error.
- **ARI split into two franchises.** `DRAFT_TEAM_MAP` mapped `ARI` → `AZ`, inventing a code
  present in no season of the dataset. 27 live 2026 players — Marvin Harrison Jr., Trey
  McBride, James Conner, Trey Benson — carried NaN for the 4th and 5th most-split model
  features. Removed the entry; Arizona's true 2026 vacated target share is 0.209.
- **Postseason games in `prior_games`.** The code had been corrected on 2026-07-24 but the
  historical rows were never rebuilt, so the shipped CSV still had **565** rows with
  `prior_games` > 17 (max 21) against 1 of 923 deploy rows. Since `prior_half_ppr` is
  regular-season only, `prior_ppg` was dividing REG points by REG+POST games — Cooper Kupp
  2022 read 17.48 pts/game instead of 21.59. Rebuild takes it to **0**. Note this
  disproportionately deflated playoff-team players, i.e. the stars.
- **Draft capital from an unguarded name join.** The 2026 name fallback scanned every draft
  class since 1980 and took `.first()` (earliest season), so 2026 WR Mario Williams inherited
  the 2006 #1 overall pick and projected 91.6 instead of ~15. Restricted to the upcoming
  class, unique names only, rookies only.
- **Snap counts joined on normalized name**, collapsing same-named players onto one snap row.
  Now joined on `player_id` via the `pfr_id` → `gsis_id` crosswalk in `players.parquet`, with
  a name fallback used only where the name is unambiguous in that season. Added a regression
  test.
- **Team play volume by season-final team.** `team_pass_rate` / `team_plays_est` aggregated
  from player-season rows keyed on `team=("team","last")`, so a traded player's whole season
  was credited to his final team. Now aggregated from the weekly rows.
- **`coach_changed` used the season-MODE head coach**, so a mid-season firing during season Y
  set the flag for Y — an event that had not happened at draft time. Now the week-1 coach.
- **NaN coerced to 0.** `out[c] = out[c].eq(True).astype(int)` turned a failed team join into
  a hard "no change", indistinguishable from a real answer. Now maps to float and preserves
  NaN, which the native-NaN trees route correctly (131 honest NaN on `qb_changed`, 80 on
  `coach_changed`; all 923 2026 rows are now NaN for `qb_changed`, which is the truth —
  the 2026 primary passer is unknowable pre-season).
- **2017 MIA/TB lost all vacated features** because Hurricane Irma postponed their Week 1 and
  `add_vacated` skipped any team-season absent from the week-1 roster feed. Added a
  season-roster fallback.
- **`is_rookie` / `years_exp` were defined differently at deploy** (first-active season) than
  in training (draft year, falling back to first-active), reintroducing the pre-2011
  truncation that fix (d) removed. Aligned; 19 players moved rookie → non-rookie.
