# Video production constraints

Every TikTok and YouTube Short must have a final rendered runtime of **180.0 seconds or less**. This is a hard ceiling, not a target or a warning. Runtime includes the lead-in, voiceover, inter-beat gaps, and CTA.

Script estimates should leave enough margin for Joseph's recorded delivery. The measured composition and final rendered file decide compliance. Do not deliver, approve, or publish a cut above 180.0 seconds; shorten it or split it into a series.
